# GrammarOfGraphics.jl

Draw a plot by describing it. You name a table, a shape to draw, and which
column goes to which part of the picture. `GrammarOfGraphics` turns that
description into an SVG.

One engine, written in Rust, does the drawing for R, Python, Julia and
JavaScript. Each language writes the plot in its own idiom and gets back the
same picture, to the byte.

## Why you might want this

**One vocabulary instead of a hundred chart types.** There is no `histogram()`
to look up, and no arguments that belong to it alone. The whole vocabulary fits
on one page, and the combinations *are* the chart types: a histogram is `bar *
bin`, a bar shape plus a binning statistic. Keep the statistic and change the
shape, and the same counts draw a line, an area or a step. You learn the words
once and they keep working.

**It says no, and says what to write instead.** Ask for something the grammar
cannot mean and you get a refusal that names the fix. Nothing is accepted and
then quietly dropped, so a plot that draws is a plot that means what you wrote.

**The same picture from four languages.** A colleague working in R, Python or
JavaScript writes the same sentence in their own idiom and gets the same file,
to the byte. A team that does not share a language can still share a plot.

**A plot is data, not code.** What you build is a description that the engine
draws, so it can be saved, compared, generated by another program, or sent over
a network. That is awkward when a plot is a live object inside a session.

**Things that usually need a second package are already here** — three
dimensions, animation, brushing, circular layouts, maps, networks, treemaps,
flow diagrams and contour maps are part of the same vocabulary rather than
add-ons with a syntax of their own.

## Install

```julia
using Pkg; Pkg.add("GrammarOfGraphics")
```

The package is in the [General registry][registration], so that is the whole
install.

**The engine comes with the package.** A plot is drawn by a compiled Rust
binary, and `Pkg.add` fetches the one for your platform as an
[artifact][artifacts], the normal Julia way to distribute a binary, so there is
nothing to build and nothing to set. The browser engine that turns and brushes
a plot in a notebook rides in the same artifact. The book's
[Julia chapter][jl-chapter] also shows how to work from a copy of the source,
where the engine is the one your own checkout builds.

[artifacts]: https://pkgdocs.julialang.org/v1/artifacts/

[registration]: https://github.com/JuliaRegistries/General/tree/master/G/GrammarOfGraphics

## Your first plot

```julia
using GrammarOfGraphics

gm = (gdp = [1000.0, 8000.0, 30000.0],
      life = [52.0, 68.0, 79.0],
      continent = ["Africa", "Asia", "Europe"])

p = data(gm) + point + x(:gdp, scale = "log") + y(:life) + color(:continent)
save_svg(p, "life.svg")
```

Read that aloud: *"Given gm: points, x is gdp on a log scale, y is life, color
by continent."* That is the whole idea. A plot is a sentence, and you can say it
before you can write it.

A table is a named tuple of columns, or any table that supports `Tables.jl`, so
a `DataFrame` works without being required.

## Five plots, five sentences

Each picture below is one sentence, drawn by the same engine. Each reads its
table from the book with `gog_table()`, so it runs as it stands. Click a
picture to open its page in the book, where the 3-D plots turn under your
mouse.

They continue from `using GrammarOfGraphics` above.

### Every hurricane since 1980, month by month

<a href="https://psychometrician.github.io/gog-book/play.html#frames-on-the-globe"><img src="https://raw.githubusercontent.com/psychometrician/gog/main/images/showcase/hurricanes.gif" alt="An animated globe, dark blue, turned toward the western Pacific. Each frame is one month, from January to December, and draws the track of every storm of hurricane strength from 1980 to 2025 in that month, colored by category." width="720"></a>

```julia
cyclones = gog_table("cyclones")
cyclones["month"] = ordered(cyclones["month"],
                            ["Jan", "Feb", "Mar", "Apr", "May", "Jun",
                             "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"])
world_borders = gog_table("world_borders")

p = data(world_borders) + zone + x(:lon) + y(:lat) + group(:country) +
    style(color = "#1c2636") +
    data(cyclones) + path + x(:lon) + y(:lat) + group(:storm) + color(:category) +
    palette(["mediumvioletred", "darkorange", "gold"]) + style(opacity = 0.6) +
    play(:month) + globe(turn = 135, tilt = 10) +
    theme(background = "#050a14", grid = "none") +
    title("Every storm of hurricane strength, 1980 to 2025, by month")
save_gif(p, "hurricanes.gif")
```

### A volcano in three dimensions

<a href="https://psychometrician.github.io/gog-book/marks/surface.html#color-by-height-per-face"><img src="https://raw.githubusercontent.com/psychometrician/gog/main/images/showcase/volcano.png" alt="Maunga Whau, a volcano in Auckland, drawn as a surface in a cube over east and north, shaded from dark purple at the base to yellow at the summit." width="720"></a>

```julia
maunga_whau = gog_table("maunga_whau")

p = data(maunga_whau) + surface + x(:east) + y(:north) + z(:elevation) +
    color(:elevation) + palette("viridis") +
    z_label("Elevation (m)") + title("Maunga Whau, a volcano in Auckland")
save_svg(p, "volcano.svg")
```

### Trade between countries, as chords

<a href="https://psychometrician.github.io/gog-book/flow.html#the-chord-diagram"><img src="https://raw.githubusercontent.com/psychometrician/gog/main/images/showcase/chord.png" alt="A chord diagram: countries around a ring, each joined to its trading partners by bands as wide as the trade between them, colored by the exporting country." width="720"></a>

```julia
trade_partners = gog_table("trade_partners")

p = data(trade_partners) + x(:billions) +
    ribbon * flow(:exporter, :importer, shared = true) + color(:exporter) +
    zone * flow(:exporter, :importer, shared = true) +
    text * flow(:exporter, :importer, shared = true) + label(:name) +
    polar() + title("Trade between countries, as chords")
save_svg(p, "chord.svg")
```

### Fifty-five years of life and income

<a href="https://psychometrician.github.io/gog-book/play.html"><img src="https://raw.githubusercontent.com/psychometrician/gog/main/images/showcase/gapminder.gif" alt="An animated scatter plot of countries, GDP per person on a log axis against life expectancy, one frame for every five years from 1952 to 2007, colored by continent and sized by population." width="720"></a>

```julia
using GrammarOfGraphics: size   # `size` is also a function in Base

gm_all = gog_table("gm_all")

p = data(gm_all) + point + x(:gdp, scale = "log") + y(:life) +
    color(:continent) + size(:population) + play(:year) +
    x_label("GDP per person") + y_label("Life expectancy") +
    title("Life and income, 1952 to 2007")
save_gif(p, "gapminder.gif")
```

### A household's money, as a Sankey diagram

<a href="https://psychometrician.github.io/gog-book/flow.html#links-in-layers"><img src="https://raw.githubusercontent.com/psychometrician/gog/main/images/showcase/sankey.png" alt="A Sankey diagram of one month's money: salary and side work flow into income, and income divides into savings, leisure, transport, food, housing and taxes, each of which divides again." width="720"></a>

```julia
budget = gog_table("budget")

p = data(budget) + y(:amount) +
    ribbon * flow(:source, :target, layered = true) + color(:source) +
    zone * flow(:source, :target, layered = true) +
    text * flow(:source, :target, layered = true) + label(:name) +
    title("A month of a household's money")
save_svg(p, "sankey.svg")
```

## What you can draw

**Shapes** — points, lines, bars, areas, steps, error bars, boxes, ribbons,
text, paths, reference lines, shaded regions, surfaces in three dimensions, and
the links of a network.

**Ways to show a column** — position, color, size, shape, texture,
transparency, a text label, or a split into one series per group.

**Statistics, written into the sentence** — binning, counting, shares, sums,
averages, medians, quantiles, running totals, ranges, confidence intervals,
smoothing curves and density estimates, and the layouts behind treemaps, flow
diagrams, networks and cluster trees. You do not calculate them beforehand.

**Arrangements** — small multiples in rows or columns, several plots in one
arrangement, a circular layout, a third dimension, maps and globes, and
animation over a column.

**Selection** — a brush that picks out the rows inside a bound you name and dims
the rest. In a browser you can drag it.

There are no chart-type functions. A histogram is `bar * bin`, a pie is a bar
chart in a circle, and a violin is a density drawn as a ribbon. Learn the words
once and they combine.

When a plot cannot be drawn, the package says so and names what to write
instead. It never quietly ignores part of what you asked for.

## Two things Julia needs

**A column is `:name`.** The colon keeps a column apart from a value, the way
R's bare names do.

**Nine words share a name with `Base`** — `count`, `sum`, `min`, `max`,
`range`, `size`, `step` and `stack` are words of the grammar here, and `map` is
the space a choropleth is drawn in, so import the ones you use:

```julia
using GrammarOfGraphics: count, sum, min, max, range, size, step, stack, map
```

`mean`, `median` and `quantile` collide the same way with the `Statistics`
standard library in a session that uses both; the same explicit import settles
which one a bare name means.
